Klik foto untuk beli di Shoppe

Pilih produk → link langsung buka di Shoppe

Cara nambah/ubah produk:

  1. Buka klik-foto.html di text editor.
  2. Edit array produk di dalam tag <script>.
  3. Untuk tiap produk: nama (judul), harga (harga), link (link afiliasi Shoppe), img (URL gambar produk).
  4. Gambar: buka link produk di browser → klik kanan foto produk → Copy image address → paste ke img.
  5. Simpen file, commit, push ke GitHub → halaman otomatis update.

Gunakan link affiliate resmi Shoppe. Pastikan sesuai dengan persyaratan program afiliasi.
